# Спільна робота ПК ↔ Mac над «Офісом ШКОЛА»

Один репозиторій: https://github.com/uaitorgua/shkola-office (гілка `master`). Інших копій коду Офісу не ведемо.

## Хто що робить
| Частина | ПК (Windows) | Mac |
|---|---|---|
| Спільний код редакторів (`shkola_office/`: InterText, InterTab, InterSlide, далі InterData) | основна розробка | виправлення, якщо щось ламається на macOS/Linux |
| Застосунок «Офіс ШКОЛА» (`shkola_office/app.py`, `main.py`) | стартове вікно, EXE, підпис, MSIX для Microsoft Store | збірка `.app` / `.dmg`, підпис і нотаризація Apple, пакет для Linux |
| Шрифти | — | підібрати вільні (OFL) заміни для Segoe UI / Segoe Print / Georgia, щоб тести на Mac проходили |
| Тести | `tests/*.py` на Windows | ті самі тести на macOS (`QT_QPA_PLATFORM=offscreen`) |

## Правила
1. Перед роботою `git pull --rebase`, після кожного кроку коміт і `git push` (обрив сесії не має нічого губити).
2. Платформна різниця — через `sys.platform` у спільному коді, не копією файлів.
3. Нове велике (InterData, нові модулі) — спершу рядок у розділі «Зараз» нижче, щоб не робити вдвох те саме.
4. Повідомлення одне одному — через сервер черги (`tasks_pc.py say` / агент Mac), з посиланням на коміт.
5. Ключі підпису (`*.pfx`, сертифікати Apple) у репозиторій не кладемо.
