# InterSlide — задум (08.11.2026, чекає «так»)

Мета: шкільні презентації, уроки й квізи за хвилини, з якісних шаблонів і власної бібліотеки графіки. Без копіювання PowerPoint/Impress.

## Що вміє
- Слайди на полотні 16:9 і 4:3; текст, фігури (є `ui/shapes.py`), зображення, таблиці й діаграми з InterTab, формули з InterText.
- Макети слайдів: титул, тема уроку, мета й результати, пояснення + малюнок, два стовпці, порівняння, хронологія, схема-кластер, підсумок, рефлексія, домашнє завдання.
- **Квізи**: питання з вибором відповіді, правда/неправда, впорядкувати, пара, вписати. Відповідь з'являється за кліком (вимога методики), опитування повністю на слайді. Підрахунок балів у режимі показу.
- Режим показу з нотатками вчителя на другому екрані, таймер, указка.
- Експорт: PPTX (python-pptx, редагується у PowerPoint/Impress), PDF, PNG-слайди, HTML-квіз для учнів (один файл, працює офлайн).

## Шаблони (власного дизайну)
Набори тем: «Класна дошка», «Зошит у клітинку», «Природа», «Космос», «Історія/пергамент», «Мінімал ГС», «Яскравий для молодших». У кожному: палітра, шрифти (вільні: Montserrat, Rubik, e-Ukraine, Arsenal), фон, 12 макетів.
Готові сценарії: урок-пояснення, урок-квіз, батьківські збори, педрада, виховна година, свято.

## Бібліотека векторних об'єктів
- Теми: шкільне приладдя, математика, фізика, хімія, біологія, географія, історія України, мови, мистецтво, спорт, свята, люди/професії, емоції, стрілки/рамки/виноски, бейджі для квізів.
- Стиль: як наші іконки — сітка, штрих, зелений + бурштиновий, плюс заливний варіант. Колір перефарбовується під тему.
- Джерела, без авторських ризиків: (1) намальовані нами (DSL `tools/make_icons.py`, розширений до ілюстрацій); (2) вільні набори з ліцензією, що дозволяє змінювати й поширювати без «share-alike» (MIT/ISC/CC0, наприклад Tabler, Lucide, Phosphor), перефарбовані під наш стиль, з переліком атрибуцій у «Про програму»; (3) ілюстрації Qwen-Image на Mac → векторизація → ручна чистка. Реєстр джерел і ліцензій — `assets/library/LICENSES.md`.
- Пошук за назвою й тегами українською, перетягування на слайд.

## Етапи
1. Модель слайда + полотно + збереження (власний формат `.islide` = zip з JSON і ресурсами) + PPTX/PDF.
2. Стрічка InterSlide, макети, 2 теми.
3. Бібліотека: 150 власних об'єктів у 10 темах + пошук.
4. Квізи й режим показу, HTML-квіз.
5. Ще теми й сценарії уроків, вільні набори іконок, перевірка PPTX у PowerPoint/LibreOffice.
